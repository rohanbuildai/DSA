## 🧠 Problem-Solving Approach

Each problem is approached with a structured methodology:

```
┌─────────────────────────────────────────┐
│  1. Understand the problem statement    │
│  2. Identify brute-force approach       │
│  3. Develop better approach             │
│  4. Arrive at optimal solution          │
│  5. Analyze time & space complexity     │
│  6. Handle edge cases                   │
│  7. Implement & test                    │
└─────────────────────────────────────────┘
```

> **Philosophy:** *Don't just solve problems — understand the pattern behind them.*
