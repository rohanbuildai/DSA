## 🧠 Problem-Solving Approach

For each problem, I focus on understanding:

1. Problem statement
2. Brute-force approach
3. Better approach, when applicable
4. Optimal approach
5. Step-by-step intuition
6. Implementation
7. Time complexity
8. Space complexity
9. Edge cases

The goal is **not simply to collect solutions**, but to understand the concepts, patterns, and trade-offs behind them.
